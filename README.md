# ✨ Bhavyasree Thadaka — Portfolio

A cinematic and modern personal portfolio website showcasing education, skills, projects, and contact information.

Designed with immersive interactions, animated sections, futuristic UI styling, and smooth scrolling experiences.

---

## 🚀 Features

### Hero Experience
- Animated hero section
- Typing animation
- Interactive cursor
- Scroll progress indicator
- Responsive layout

### About Section
- Personal introduction
- Education details
- Interests and hobbies
- Information cards

### Skills Showcase
- Animated skill bars
- Technology cards
- Interactive hover effects

### Project Showcase
- Project gallery
- Technology badges
- Smooth reveal animations

### Contact Experience
- Contact information
- Social profile section
- Interactive message form
- Toast notifications

---
